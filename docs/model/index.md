# モデル

**前提となる用語：** [はじめに](../guide/index.md)の4ページ。特に[モデルの全体像](../guide/overview.md)の三つの概念（制度化レベル、評価軸、自動化段階）。

この節は、モデルの本体です。[モデルの全体像](../guide/overview.md)で概観した三つの概念を、レベル別、軸別、段階別に詳しく定義し、最後に判定の規則を示します。上から順に読んでください。

| 順 | ページ | 内容 |
|---|---|---|
| 1 | [レベル別ビュー](levels.md) | 各レベルで5軸がどの状態にあるかを横断で読む。「次のレベルの全体像」を掴む |
| 2 | [軸別ビュー](axes.md) | 各軸がレベルごとにどう変わるかを縦に読む。「この軸で次に何を整備するか」を決める |
| 3 | [自動化段階](automation.md) | A1〜A4の定義と、レベルとの関係。統制不足の意味 |
| 4 | [判定規則](rules.md) | レベルの決め方、証拠の種類、確定と暫定上限、再評価 |

**次に読む：** [レベル別ビュー](levels.md)
