# CMMIとの対応

本モデルは、CMMIの成熟度レベルの**構成を参考にして**レベルを定義しています。CMMIの公式な派生物でも、CMMIアプレイザルの代替でもありません。本モデルのレベルは、CMMIの成熟度レベルの認定を意味しません。

## レベルの対応

| 本モデル | CMMIの成熟度レベル | 共通する考え方 |
|---|---|---|
| 未到達 | レベル0 Incomplete | 作業が完了まで至らない、または実施されていない |
| レベル1 属人的 | レベル1 Initial | 成果が個人に依存する |
| レベル2 プロセス確立 | レベル2 Managed | PJ単位で計画・監視・制御する |
| レベル3 組織標準化 | レベル3 Defined | 組織標準からテーラリングする |
| レベル4 定量管理 | レベル4 Quantitatively Managed | 定量的な目標と統計的手法で管理する |
| レベル5 継続的最適化 | レベル5 Optimizing | 実績に基づき継続的に改善する |

## 本モデルが独自に定めていること

| 項目 | 内容 |
|---|---|
| 評価軸 | CMMIのプラクティス領域ではなく、AI利用に固有の5軸で評価する |
| 自動化段階 | 制度化の度合いとは別に、AIの実行範囲をA1〜A4で記録する |
| ゲート | 自動化段階ごとに前提レベルを定め、超過を統制不足として扱う |
| 判定方法 | 基準カタログとの照合で判定する。確定と暫定上限を併記する |

## 自動化段階を分けた理由

CMMIのレベルは、プロセスがどれだけ制度化されているかを表します。AIがどこまで自動で実行するかは、それとは別の性質です。両者を一つのレベルにまとめると、「標準化されていないが自動化は進んでいる」状態を表現できません。この状態はリスクが高いため、分けて記録し、統制不足として検出します。

## 商標について

CMMIは、ISACAの登録商標です。本モデルでの言及は、レベル構成の参考元を示す目的に限ります。公開にあたっての表記は、各組織の法務部門で確認してください。
