# 用語集

| 用語 | 意味 |
|---|---|
| PJ | プロジェクト。本モデルの評価単位 |
| Agent Skill | AIエージェントが再利用する、手順・判断基準・品質基準・成果物形式をまとめたもの |
| 開発標準資産 | 標準フレームワーク、テンプレートリポジトリ、方式設計の総称 |
| 接続キット | 権限設定、CI定義、エージェント実行基盤をまとめた組織標準の構成 |
| テーラリング | 組織標準を、PJの条件に合わせて調整すること。差分と理由を記録する |
| ローカル事前検証 | 個人の作業環境で、共有前に行うビルド・静的解析・テスト |
| 共有CI | チームが共有するCI環境。対象コミットに対して定義された検証を実行する |
| MR・PR | マージリクエスト、プルリクエスト |
| 制度化レベル | プロセスがどれだけ定着しているかを表す、レベル1〜5の段階 |
| 自動化段階 | AIがどこまで人手を介さず実行するかを表す、A1〜A4の段階 |
| 統制不足 | 自動化段階が、前提とするレベルを超えている状態 |
| 確定 | 証拠で確認できた判定結果 |
| 暫定上限 | ヒアリング未了の基準をすべて充足とみなした場合の判定結果 |
| 申告 | 回答者、回答内容、証拠の所在を記録したヒアリング回答 |
| 基準工数 | AIを使わない場合の工数。効果算定の分母になる |
| 工程性能ベースライン | 複数PJの実績から求めた、工程の通常の性能範囲 |
| 帰属ルール | 削減効果を、価格還元・利益・品質への再投資のどれに充てるかの取り決め |
| 制約工程 | 案件全体のリードタイムや品質を決めている工程 |
