# 軸別チェックリスト

軸ごとの判定基準です。[評価の進め方](../assess/howto.md)の手順1で、基準ごとに「充足」「未充足」「要ヒアリング」を付けるときに使います。基準には `SK-2-04` のようなIDが付いています。先頭が軸（SK：Agent Skill、ENV：環境との接続、STD：開発標準資産、PRC：AI前提の開発プロセス、EST：AI前提の見積もり・PJ収支）、次がレベル、最後が連番です。

各ページは基準の正本（`criteria/criteria.json`）から生成しています。評価下書きを作るSkillも同じ正本を使うため、ページとSkillの基準は常に一致します。

| ページ | 基準の主な確認元 |
|---|---|
| [Agent Skill](skill.md) | リポジトリ |
| [環境との接続](environment.md) | リポジトリ、共有環境の設定 |
| [開発標準資産](standard-assets.md) | リポジトリ |
| [AI前提の開発プロセス](process.md) | 計画書、WBS、役割定義 |
| [AI前提の見積もり・PJ収支](estimate.md) | 見積書、原価記録 |
| [自動化段階](automation.md) | リポジトリ（CI定義） |

「確認元」の意味は次のとおりです。

| 確認元 | 意味 |
|---|---|
| リポジトリ | リポジトリだけで充足・未充足を判定できる |
| リポジトリまたはヒアリング | リポジトリ内に証拠がなければ、ヒアリングで確認する |
| ヒアリング | 証拠は通常リポジトリの外にある |

**次に読む：** [Agent Skill](skill.md)から順に各軸の基準を確認します。軸別の確認が済んだら[工程別チェックリスト](../process/index.md)へ進みます。
