# 効果の目安

**前提となる用語：** [制度化レベルと自動化段階](../guide/overview.md)、[工数、基準工数](../guide/terms.md)

> このページの数値は業界統計でも実績値でもありません。案件計画やPoC評価に使う**初期仮説**です。実績値を取得した後は、組織と案件の特性に合わせて更新してください。

## 状態別の目安

効果の大きさを決めるのは自動化段階で、レベルはその効果を再現・測定できるかを決めます。

| 状態 | AI適用作業の工数削減率 | 案件全体の工数削減率 | 効果の扱い | 主な効果発生源 |
|---|---:|---:|---|---|
| レベル1／A1 | 10〜20% | 2〜5% | 個人差が大きく、測定できない | コード生成、文書作成、調査、個人Skillの反復利用 |
| レベル2／A2 | 20〜35% | 5〜12% | PJ内で測定できる | 共通Skill、標準テンプレート、共有環境との接続 |
| レベル3／A3 | 35〜55% | 12〜25% | PJ間で比較できる | CI/CD連携、テスト自動実行、イベント駆動、スケジュール実行 |
| レベル4〜5／A4 | 50〜70% | 20〜35% | 計画値として使用できる | Skillの自律選択、実装・検証・修正の自律反復 |

軸ごとにレベルが異なるPJでは、いずれか一つのレベルを表に当てはめて削減率を決めません。工程ごとの実測工数と品質を基に検証します。

## 効果から差し引く負担

AI利用の効果には、短縮された時間だけでなく、次の負担を含めます。[算定式](formula.md)は、これらを控除した純効果を求めます。

- AIへの指示を作成する工数、入力資料を準備する工数
- AIの出力を確認する工数、誤出力を修正する工数、再実行する工数
- Agent Skillを開発・保守する工数
- 開発標準資産を整備・保守し、案件へ適用・更新する工数
- AIエージェントの実行基盤を運用する工数
- AIの利用料、習熟・育成の費用
