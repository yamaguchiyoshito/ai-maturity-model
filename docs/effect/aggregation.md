# 全社集計

PJの実績を合算し、利用者アンケート以外の指標で全社の効果を測定します。

## PJごとに記録する指標

PJごとに識別子、対象期間、対象工程、対象作業量を付け、次の指標を記録します。

| 指標 | 記録する内容 | 主な記録元 |
|---|---|---|
| 純削減工数・純効果額 | 基準工数、AI利用後の総工数、費用を用いた[算定式](formula.md)の結果 | 工数記録、費用記録、比較対象の作業実績 |
| リードタイム・待ち時間 | 作業開始から完了までの時間、レビュー待ち・テスト待ちの時間 | Issue、MR・PR、共有CIの時刻記録 |
| 手戻り・品質 | 再作業工数、重大指摘、不具合、後工程流出不具合 | 工数記録、レビュー記録、不具合管理記録 |
| 成熟度・検証の実施状況 | 軸別のレベル、自動化段階、ローカル事前検証と共有CIの実行実績 | 本成熟度モデルの評価結果、実行ログ、共有CIの記録 |

## 集計の規則

1. **集計対象は、見積もり・PJ収支軸がレベル2以上のPJです。** 基準工数を記録していないPJは「効果未測定」として分け、ゼロ効果とは扱いません。
2. **削減率は単純平均しません。** 対象PJの純削減工数合計を、同じ対象PJの基準工数合計で割ります。
3. **カバー率を併記します。** 集計対象PJ数と、対象PJの基準工数が全PJの基準工数に占める割合を示します。
4. **同じ実績を重複計上しません。** PJの識別子、対象期間、対象範囲をそろえます。
5. **成熟度や実行回数から削減工数を算出しません。** レベルの向上、実行回数、テストの成功件数は、効果の根拠になりません。
6. **目安値を実績として集計しません。** [効果の目安](estimate.md)の値は仮説です。

**単純平均しない理由の例**：基準工数1,000時間のPJ Aで純削減率10%（100時間削減）、基準工数100時間のPJ Bで純削減率50%（50時間削減）だったとします。単純平均は30%ですが、全社で見ると（100 + 50）÷（1,000 + 100）= 約14%です。小さなPJの高い削減率が、全社の効果を実態より大きく見せます。

## 比較条件の記録

比較する作業の規模・難易度・品質条件、基準工数の設定根拠、AI以外の改善要因を記録します。

## 進捗の指標

全社の効果測定がどこまで進んでいるかは、**集計対象PJの基準工数カバー率**で把握できます。この値が低い間は、合算した効果額が全社を代表しているとは言えません。
