# 算定式

**前提となる用語：** [工数、基準工数、PJ原価、請負と準委任](../guide/terms.md#契約と収支)

この算定は、見積もり・PJ収支軸のレベル2で必須とする手順です。

## 先に押さえる二つの言葉

| 言葉 | 意味 |
|---|---|
| 基準工数（従来工数） | AIを使わなかった場合に、その作業にかかると見込まれる工数。過去の類似作業の実績、または見積もり時の標準値から決め、根拠を記録する。これがなければ効果は計算できない |
| 按分 | Skillの保守や標準資産の整備のように、複数の作業や複数のPJにまたがる工数を、利用した割合で各作業に割り振ること |

## 1. AI適用作業の純工数削減率

```text
純工数削減率 =（従来工数 − AI利用後の総工数）÷ 従来工数

AI利用後の総工数
  = AI実行時の人作業工数
  + 確認工数
  + 修正工数
  + 再実行工数
  + Agent Skillの按分保守工数
  + 開発標準資産の按分整備・保守・適用工数
```

## 2. 案件全体の工数削減率

```text
案件全体の工数削減率
  =（AI適用作業の純削減工数合計 − AI基盤運用工数）÷ 案件全体の基準工数
```

## 3. 金額換算

```text
生産性効果額 = 案件全体の純削減工数 × 標準時間単価

純効果額
  = 生産性効果額
  − AI利用料
  − 基盤費（利用料・インフラ費。運用の人件費は含めない）
  − 教育・支援費
```

## 数値を入れた例

販売管理PJの「画面の入力チェック処理の実装」で、基準工数が40時間だったとします。

```text
AI実行時の人作業工数（指示の作成、入力資料の準備）   4時間
確認工数                                              6時間
修正工数                                              4時間
再実行工数                                            1時間
Skillの按分保守工数                                   2時間
標準資産の按分整備・保守・適用工数                    3時間
AI利用後の総工数                                     20時間

純工数削減率 =（40 − 20）÷ 40 = 50%
```

「AIが生成した時間は30分だった」という数字だけを見ると削減率は98%に見えますが、確認、修正、手順書と標準資産の保守を含めた純削減率は50%です。本モデルが測るのは後者です。

## 二重控除を避ける

Agent Skillの保守と開発標準資産の整備・保守・適用は、**手順1で工数として控除済み**です。手順3で費用として再度差し引きません。同様に、基盤運用の人件費は手順2で工数として控除済みのため、手順3の基盤費には含めません。

| 負担 | 控除する手順 | 単位 |
|---|---|---|
| 確認・修正・再実行 | 1 | 工数 |
| Agent Skillの保守 | 1 | 工数（按分） |
| 開発標準資産の整備・保守・適用 | 1 | 工数（按分） |
| AI基盤の運用 | 2 | 工数 |
| AI利用料、基盤の利用料・インフラ費 | 3 | 金額 |
| 教育・支援 | 3 | 金額 |

## 削減した時間の扱い

削減された時間を、すべて費用削減として扱う必要はありません。テストケースの追加、レビュー密度の向上、非機能要件の検証、顧客との仕様確認、技術的負債の解消、納期短縮などへ再配分した場合は、その用途を記録します。

契約形態によって、削減効果の帰属は変わります。[軸別ビューの見積もり・PJ収支](../model/axes.md)を参照してください。
