# 効果を測る

成熟度は実行能力や整備状況を示す指標です。生産性効果は成熟度からは算出せず、PJの実績に基づいて測定します。この節では、計画に使う目安の値、PJ単位の算定式、全社での集計方法を順に説明します。

| 順 | ページ | 内容 |
|---|---|---|
| 1 | [効果の目安](estimate.md) | 計画やPoC評価に使う初期仮説の値。実績ではない |
| 2 | [算定式](formula.md) | 純工数削減率と純効果額の計算方法。数値を入れた例付き |
| 3 | [全社集計](aggregation.md) | PJの実績を合算する方法。単純平均しない理由 |
