# AI利用成熟度モデル（要約）

基準の正本は `criteria.json`。この文書は判定時に定義を確認するための要約である。

## レベル（CMMIのレベル構成を参考）

| レベル | 名称 | 再現できる範囲 |
|---|---|---|
| 未到達 | — | 再現できない（AI未利用、単発利用） |
| 1 | 属人的 | 本人 |
| 2 | プロセス確立 | PJ内（計画・版管理・レビュー・実績測定） |
| 3 | 組織標準化 | 他PJ（組織標準からテーラリングし、差分・例外・承認を記録） |
| 4 | 定量管理 | 予測（工程性能ベースラインと数値の閾値）※PJ単独では判定しない |
| 5 | 継続的最適化 | 改善（実績から標準を更新）※PJ単独では判定しない |

## 評価軸

| ID | 軸 | 主な証拠の所在 |
|---|---|---|
| SK | Agent Skill | リポジトリ（SKILL.md、scripts、Git履歴） |
| ENV | 環境との接続 | リポジトリ（エージェント設定、CI定義）＋共有環境の設定 |
| STD | 開発標準資産 | リポジトリ（README、依存定義、方式設計、ADR） |
| PRC | AI前提の開発プロセス | 計画書、WBS、役割定義（多くはリポジトリ外） |
| EST | AI前提の見積もり・PJ収支 | 見積書、原価記録（リポジトリ外） |

## 自動化段階

| 段階 | 状態 | 前提レベル |
|---|---|---|
| A1 | 人が起動し、ローカルで実行 | 1 |
| A2 | 共有環境に接続し、MRまで作成 | 2 |
| A3 | サーバサイドで、イベント・スケジュールを契機に実行 | 3 |
| A4 | 統制範囲内で自律反復 | 4（本スキルでは判定しない） |

前提レベルを超えた自動化は「統制不足」として報告する。

## 基準の source

| source | 意味 | 使える判定 |
|---|---|---|
| repo | リポジトリだけで判定できる | met / not_met |
| either | リポジトリ内にある場合と外にある場合がある | met / hearing |
| hearing | 通常はリポジトリ外にある | met（証拠または申告）/ hearing |
